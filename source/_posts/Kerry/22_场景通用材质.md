# 地表材质
## 高度混合因子
### 高度混合
一般来说，场景中的地表都是好几层纹理混合起来形成的结果，例如草地和泥土，草地与砂石路等等之间的混合，这种混合我们一般会通过**顶点色**来实现，也就是**通过顶点色在两种材质之间进行线性插值**。我们可以通过**顶点色笔刷**在 Unity 中改变两种材质混合的比例，以此来单独显示其中一种材质。但是这种做法会导致在材质与材质过渡的部分过于平滑，因此，**在过渡区域我们一般会使用高度图/高度混合**`Height Lerp`**来实现**。

`Height Lerp`同样会使用到顶点色，也就是顶点色在$[0,0.5]$区间表示第一种材质，在$[0.5,1]$区间表示第二种材质，我们将这种用于定义材质之间过渡关系的变量命名为`Transition`，将第二种材质的高度图命名为`Height`。

我们首先计算`saturate((Height - 1) + (Transition * 2))`，这样一来，后者就扩大到了$[0,2]$，前者变为$[-1,0]$，也就是说，我们可以将`Transition`看做水位线：

当`Transition = 0`时，结果无法抵消`-1`的影响，依然被`clamp`在 0 的位置，也就是完全显示第一种材质；

当`0 < Transition < 0.5`时，随着`Transition`不断增大，`Height`中最高的部分将先突破`Clamp`的限制，也就是大于 0，因此高度最高的部分将会先显示出第二种材质；

当`Transition = 0.5`时，结果等于`Height`，但这并不意味着第二种材质已经被完全显示出来，因为我们将使用计算结果对第一种材质和第二种材质进行线性插值，而`Height`位于$[0,1]$，因此此时依然处于两种材质的过渡区域，且高度越高的部分越接近第二种材质；

当`Transition > 0.5`时，`Height`中接近 1 的区域在加上`Transition * 2`之后结果将会大于 1，然后被`Clamp`在 1 的位置，也就是说，高度越高的部分将会越先等于 1，也就是越先完整显示出第二种材质。

### 增强对比度
为了让过渡区域更加锐利，我们还需要增强上述结果的对比度，令上述结果为`BaseMask`，我们可以使用`lerp(-BlendContrast, 1 + BlendContrast, BaseMask)`的方式来增强对比度，之所以使用`(-BlendContrast, 1 + BlendContrast)`，是因为我们需要让`BaseMask`以 0.5 为中心向两侧缩放（$\frac{-BlendContrast + 1 + BlendContrast}{2} = 0.5$），然后我们将结果`Clamp`在$[0,1]$区间即可。

### 封装节点
我们会将上述节点封装为`HeightLerp`节点，节点的输入参数分别是`BlendContrast`、`Height`和`Transition`。

## (legacy)材质叠加混合
叠加混合指的是，通过上述计算出的高度混合因子，先将第一种材质的`BaseColor`、`Roughness`、`Normal`、`AO`等参数与第二张材质混合，然后将混合的结果再与第三种材质进行混合。但是这种混合方式的缺点在于，**我们需要严格规定三种材质的排列顺序才能得到正确的结果**。

## 材质权重混合
为了解决直接叠加混合的缺点，我们引入了权重混合的方式。我们首先需要提取出顶点色`RGB`分量中的最大值，将其加上各自对应的高度图`Height`之后将其减去$BlendContrast \in [0,1]$，作为顶点色的`Threshold`，然后将顶点色的各分量分别减去该`Threshold`，然后将其`Clamp`在 0 的位置，即：

$$ w_R = max(R + {Height}_1 - Threshold, 0) \\[5pt]
w_G = max(G + {Height}_2 - Threshold, 0) \\[5pt]
w_B = max(B + {Height}_3 - Threshold, 0) $$

这样一来，我们先忽略高度图的部分，当`BlendContrast = 1`时，结果中除了顶点色最大的分量以外都是零，也就是只会显示**顶点色**最大的分量对应的材质，`BlendContrast < 1`时，其余两个材质的权重将会影响最终的结果。当我们为每个分量添加上高度图之后，这就意味着**高度越高的材质的权重越大**，换句话说，**高度越低的材质将会优先抢占高度较低的部分，高度越高的材质将会优先抢占高度较高的部分**。这部分与上述`HeightLerp`的过程类似，也就是**三种材质将会按照高度来平滑过渡**。

但此时上述三个权重之和并不为 1，因此我们还需要将他们归一化，即：

$$ sum = wR + wG + wB \\[5pt]
a = wR / sum \\[5pt]
b = wG / sum \\[5pt]
c = wB / sum \\[5pt]
final = tex1 \times a + tex2 \times b + tex3 \times c $$

# 导入其他模型
## 湖泊渲染
此处我们将直接复用第 21 章的风格化水体的`Shader`，但区别在于我们原先使用平面反射来获得反射贴图，此处我们将使用反射探针。

+ `Box Projection`：反射探针默认情况下会将反射贴图渲染到一张天空盒中，勾选此选项后则会渲染到一个类似于`CubeMap`的立方体中，适用于渲染室内场景，此处我们还是选择勾选该选项，因为渲染到天空盒会导致水面上的倒影距离太远，无法匹配岸边的物体。

## 河流渲染
河流与湖泊最大的区别在于河流的流动性，一般来说河流的流动方向与其`uv`方向有关，因此我们将使用`uv`来采样法线贴图，而不是使用世界坐标。同时我们依然保持采样两次法线贴图来保证河流表面的上下起伏，但是区别在于，我们原先两次采样的方向相反，这是为了营造水面的波峰与波谷，但是河流表面的顶点理论上来说都会向着流动的方向移动，因此我们采样的方向也应当保持一致，只需要改变第二次采样的`Tilling`值即可。

除了需要修改表面法线采样的方式，我们还需要修改河流的泡沫，毕竟河流表面的泡沫也需要跟随流动方向移动。我们将通过直接采样两次噪声贴图来添加表面的泡沫效果，但是由于伯努利原理，**河流表面有的位置流动得快，有的部分流动的慢**，且这两者的比例会随着河流当前的位置而不断变化。一般来说，我们可以**使用河流面片的顶点色来区分**这两者，也就是将顶点色作为两次采样结果的线性插值因子。

然后我们将上述结果作为`Height Lerp`的`Height`，将`FoamFactor`作为`Transition`，也就是我们将泡沫区域看成高度图，有泡沫的地方高度就高，没有泡沫的地方高度就低，也就是会显示水面的颜色，这样一来我们就可以通过`BlendContrast`得到对比度较高的卡通风格的水面泡沫。

## 河流与湖泊的交界处渲染
我们可以**将两者的顶点色的**`Alpha`**通道作为两者的渲染透明度**，然后通过顶点色笔刷来人工修改交界处的混合效果，同时我们还需要注意两者的覆盖关系，由于河流面片在湖泊上方，因此我们需要保证河流的渲染队列晚于湖泊。

同时河流并入湖泊的地方理论上还会产生大量的泡沫，这部分泡沫的渲染队列需要晚于河流与湖泊，我们可以直接对一张面片绘制顶点色来直接作为泡沫`Height Lerp`的`Transition`。
