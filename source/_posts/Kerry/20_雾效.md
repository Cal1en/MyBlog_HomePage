# `Indirect Specular Color`
首先我们需要给我们的示例场景添加基本色，我们可以通过`ASE`自带的`Indirect Specular Color`节点来快速添加天空球的`IBL`颜色。

# 基于世界空间的线性雾
## 深度雾
我们在第19章提到过通过线性重映射的方式来计算衰减距离，这种计算方式同样适用于线性雾，我们只需要指定雾效的起始与终止距离，以及当前顶点的世界空间坐标与摄像机世界空间坐标之间的距离。但不同的是我们希望距离越大雾效越浓，因此我们只需要使用`One Minus`即可。

$$f = 1 - saturate(\frac{FogEnd - Distance}{FogEnd-FogStart})$$

### 封装节点 `Amplify Shader Function`
我们可以通过新建`Amplify Shader Function`文件来封装节点，文件名即为我们想要自定义的节点名称，在该类型的文件中通过新建`Function Input`节点来指定节点的输入。

# 基于深度图的线性雾
我们曾在《入门精要》中学习过基于深度纹理的雾效，之所以选择使用深度纹理，是因为如果我们使用上述的方式来添加雾效的话，这就意味着我们需要手动对场景中每个物体添加计算雾效的节点，操作过于繁琐，因此我们可以通过深度纹理的深度来转换出观察空间中每个顶点的世界空间坐标（转换过程见《入门精要》15.5 节）。

这部分转换过程虽然**性能极高，但是代码量较大，而且需要使用顶点着色器与片元着色器之间的转换**，因此`ASE`为我们提供了`Reconstruct World Position From Depth`节点来直接获得从深度纹理转换出的世界空间坐标，这部分转换过程与《入门精要》15.4 节中的转换方法一致，也就是通过`uv`和深度值拼凑出裁剪空间坐标，然后通过**观察*裁剪**反变换来得到世界空间坐标。**这部分计算过程完全在片元着色器中进行，而且需要使用矩阵乘法，性能开销大，但是实现简单**。

+ **一个**`Shader`**中不能出现多个**`Reconstruct World Position From Depth`**节点。**

## 修改上述代码
首先我们需要将`Shader`更换为后处理`Shader`；

我们需要将世界空间坐标替换为由`Reconstruct World Position From Depth`求出的世界空间坐标，并根据新的世界空间坐标重新计算`View Dir`，即摄像机世界空间坐标减去新的顶点世界空间坐标，然后将其归一化；

同时我们还需要添加`C#`代码来开启获取深度图，并使用后处理函数。

## 分离山脉与天空
我们完成了上述操作之后，大概率会发生以下两点问题，一是画面的上半部分亮度明显增加了，二是用于遮蔽山脉与天空的交界处的雾效没有之前那么浓了，这是因为我们原先对天空盒添加高度雾的时候是直接修改了天空盒的材质，这意味着这部分高度雾只会在画面中天空盒的部分显示，而现在我们是直接进行屏幕后处理，会对画面内所有的顶点应用修改，因此我们需要想办法分离画面中的山脉与天空，将他们分成两部分分别添加高度雾与深度雾。

我们可以利用深度雾的参数对山脉的高度雾部分进行限制，即将两个参数相乘；同时我们也可以再计算一个深度雾参数为天空盒使用，这部分并不是用于计算深度雾，而是用来限制天空盒的高度雾只在这部分深度内起效。

# 结果
```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

[ExecuteInEditMode()]
public class CS17_GlobalFog : MonoBehaviour 
{
	[SerializeField] private Material _material;

	void Start () 
	{
        Camera.main.depthTextureMode = DepthTextureMode.Depth;
	}

    private void OnRenderImage(RenderTexture source, RenderTexture destination)
    {
        if(_material == null || !_material.shader.isSupported)
            Graphics.Blit(source, destination);

        else
            Graphics.Blit(source, destination, _material);
    }
}
```
