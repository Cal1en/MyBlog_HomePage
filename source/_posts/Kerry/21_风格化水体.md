# 水深
由于水体属于半透明物体，因此并**不会开启深度写入**，我们就可以使用`Reconstruct World Position From Depth`节点，通过深度纹理来转换出背景（水底）的世界空间坐标，然后将我们可以使用当前顶点的世界空间坐标的`y`值减去水底的`y`值来计算出水深（应该也可以使用第 16 章中的交界处边缘光的算法来获取深度，不过由于我们后面还需要使用到水底的世界空间坐标，因此这里直接使用`Reconstruct World Position From Depth`节点来一并获取）。

# 水体颜色
## 浅水和深水
我们可以通过上述求出的水深来对浅水色和深水色做线性插值，但是水深显然不是一个位于$[0,1]$区间的值，因此我们可以将其取负后作为自然常数e的指数，即：

$$ Weight = e^{-Depth} \in (0,1] $$

我们接下来将会多次使用上述方式，分别用来区分焦散区域，岸边区域等。

## 菲涅尔反射基本色
我们除了会使用菲涅尔反射来控制反射光和折射光之间的比例以外，在视角逐渐远离法线方向时，我们除了能观察到明显的反射光以外，反射的基本色也会逐渐加深，也就是我们会在反射的画面的基础上再添加一层基本色。我们只需要使用`Fresnel`，将浅水与深水的插值结果再和该基本色做插值即可。

## 透明度
显然水深越浅越透明，我们可以使用水深来控制透明度，但是调整起来不太方便，我们可以直接使用上述插值结果的`Alpha`通道来控制透明度。

## 焦散
由于水面法线的不均匀性，阳光打在水面上形成的折射光方向同样不均匀，但是由于水面波纹分为波峰和波谷，在同一波峰或同一波谷上的法线大致是相同的，这就导致折射光在这些方向上较为集中，在水底形成集中的亮条纹，该现象被称为焦散。

焦散在宏观上看起来很像法线的扰动效果，因为水面法线在不断波动，但实际上我们会直接使用焦散的纹理贴图来制作。但是焦散的采样方式比较特殊，我们会对同一张焦散贴图采样两次，且两次采样的方向相反，这样采样出来的结果将会类似于驻波，焦散的光斑将会在原地闪烁，而非向同一个方向移动。

## 边缘处理
### 边缘透明度/颜色
在水面与地面的交界处，由于水深过浅，我们应当能看到极其透明的颜色，这部分透明度没有办法使用上述浅水色的透明度来直接控制，因为浅水区域过大，因此我们需要再用本章 2.1 节中提到的水深插值因子的计算方式再计算一个边缘插值因子，作为边缘色和水体颜色的插值因子。

显然边缘区域的颜色就是水底的颜色，我们将再创建一个`ShoreColor`与水底颜色相乘，便于控制边缘颜色。

# 岸边泡沫
卡通风格的泡沫一般呈白色状，形状不规则，但边缘锐利，同时泡沫越接近岸边，颜色越白，大小越小。

## 泡沫所在区域
我们可以通过`clamp`后的水深来计算出泡沫所在区域，即：

$$ FoamFactor = 1 - saturate(WaterDepth / FoamRange) $$

## 泡沫波形
泡沫与水波一样，会随着时间缓慢地向岸边移动，同时泡沫是由水波产生的，因此也会产生波形。我们使用`sin`函数来制作随时间不断产生的泡沫，只需要将上述`FoamFactor`乘以频率`FoamFrequency`后加上时间变量即可。

但是这样计算出的波形是规则的长条状，颜色也符合`sin`函数的特征，即在波峰两侧递减，因此，我们还需要将波形叠加一张噪声贴图来打乱边缘。

但是添加完噪声贴图后，泡沫的边缘依然是软边缘，因此我们还需要用到`step`函数，我们将上述叠加过噪声的结果减去`FoamDissolve`来控制消融范围，然后传入`step`函数，`step`函数的阈值可以使用`FoamFactor`来控制，毕竟越接近岸边，泡沫越小，也就是需要更高的阈值。

最后，我们还需要控制一下泡沫从产生到消失之间的渐变，也就是刚产生时颜色较淡，到岸边时颜色最白。我们可以使用`smoothstep`函数来完成。

我们可以使用上述结果作为泡沫颜色和水体颜色的插值因子，此处我们选择直接先和泡沫颜色相乘，并确保泡沫颜色的`Alpha`通道为 1，这样一来相乘之后的`Alpha`通道依然等于上述结果，我们就可以用该`Alpha`通道与水体颜色做插值。

# 水体运动
## Gerstner Wave
[https://catlikecoding.com/unity/tutorials/flow/waves/](https://catlikecoding.com/unity/tutorials/flow/waves/)

观察海浪的形状我们不难发现，海浪的波峰呈尖峰状，而波谷变化则较平缓。我们通常会使用`Gerstner`波来模拟波浪，其作用原理如下所示。

<!-- 这是一张图片，ocr 内容为： -->
![](/img/Kerry/21_风格化水体/1778847435808-ed321fdd-e1ee-4a1a-be71-c51c722f79f5.gif)

```csharp
float3 GerstnerWave (float4 wave, float3 p, inout float3 tangent, inout float3 binormal) 
{
    float steepness = wave.z;
    float wavelength = wave.w;
    float k = 2 * UNITY_PI / wavelength;
    float c = sqrt(9.8 / k);
    float2 d = normalize(wave.xy);
    float f = k * (dot(d, p.xz) - c * _Time.y);
    float a = steepness / k;
    
    //p.x += d.x * (a * cos(f));
    //p.y = a * sin(f);
    //p.z += d.y * (a * cos(f));

    tangent += float3(
        -d.x * d.x * (steepness * sin(f)),
        d.x * (steepness * cos(f)),
        -d.x * d.y * (steepness * sin(f))
    );
    binormal += float3(
        -d.x * d.y * (steepness * sin(f)),
        d.y * (steepness * cos(f)),
        -d.y * d.y * (steepness * sin(f))
    );
    return float3(
        d.x * (a * cos(f)),
        a * sin(f),
        d.y * (a * cos(f))
    );
}
```

我们将叠加三种`Gerstner Wave`来计算顶点位置以及法线的偏移程度，以此来模拟波浪的效果。要注意的是，上面的代码中的`tangent`、`binormal`方向均为世界空间方向，即`tangent`初始方向为`x`正方向，`binormal`为`z`正方向，`normal`为`y`正方向，因此顶点法线`normal = tangent * binormal`。

然后我们可以通过偏移后的位置的`y`分量减去原世界坐标的`y`来计算出波峰，然后为其添加颜色。

## 水面上的物体
