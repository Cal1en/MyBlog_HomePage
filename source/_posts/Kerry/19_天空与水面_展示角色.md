# 自制天空盒
如果我们想用一个球体来代替天空盒，那么我们将会遇到的第一个问题便是球体并不会被渲染进摄像机，因为球体大小过大而无法进入摄像机的视椎体内部，因此画面中将会出现Unity的默认天空盒。由于摄像机的剔除遮罩功能无法解决这类由于视椎体导致的剔除，我们需要利用到Unity的裁剪空间。

## Unity的裁剪空间
我们曾在《入门精要》中提到过，裁剪空间理论上是一个从$[-w,-w,-w]$到$[w,w,w]$的正方体，但是Unity为了兼容全平台的API，在`Shader`（GPU）中使用的裁剪空间实际上是一个从$[-w,-w,0]$到$[w,w,w]$的长方体，即近裁剪面的`z = 0`，**但是在`C#`（CPU）阶段依然在使用前者的正方体裁剪空间。**

## 修改`Shader`
我们已经知道这类遮挡剔除是因为摄像机距离球面的距离大于远裁剪平面的范围所导致的，那么**如果我们能将天空球的顶点的`z`减小到视椎体范围以内，就能避免剔除**。

+ 这种做法只修改了每个顶点的`z`值，而没有修改`xy`，理论上可能会导致视觉的扭曲，但由于距离较远，我们可以忽略这一点。
+ 此外，为了避免错误的遮挡剔除关系，我们肯定希望天空球的顶点`z`值应尽可能靠近摄像机的远裁剪平面，但是为了避免边界情况，我们应避免其恰好等于远裁剪平面的距离。

### `Z-Fighting`和`UNITY_REVERSED_Z`
在诸如`Vulkan`等现代图形API中，它们的裁剪空间以及NDC空间的`z`轴映射关系均是相反的，以NDC空间为例，它们的远裁剪平面位于`z = 0`，近裁剪平面位于`z = 1`，这是为了避免`Z-Fighting`的情况。

所谓`Z-Fighting`，指的是当两个平面的深度过于接近时，两个平面的渲染结果可能会重叠闪烁，如果我们能够提升深度的精度，就能很好的减少这种情况，但问题在于，**老牌图形API的深度精度是随着深度增大而迅速递减的**，这是由于以下两个原因所造成的：

+ 计算机的浮点数精度往往都是在0附近最大，向两侧递减。
+ 在从观察空间变换到裁剪空间时，我们需要做投影变换，然后转入NDC坐标空间。通过一定的数学推导，我们不难发现，$z_{ndc}$和$-\frac{1}{z_{view}}$成正比，这也就意味着在NDC空间，即$z \in [0,1]$范围内，绝大部分都分配给了$z_{view}$较小的情况，这也就意味着近处的深度精度高，远处的深度精度迅速降低。

因此，**现代图形API会将`z`轴映射关系取反**，也就是利用上述第一点，将浮点数的精度优势放置在深度较大的区域，投影矩阵带来的精度优势不变，依然在精度较小的区域，这样一来，**场景中深度的精度就更加趋于线性**，从而不会像原先一样浪费近处的深度精度优势。

我们可以在Unity中通过 **`UNITY_REVERSED_Z`** 宏来判断当前图形API是否开启了`z`轴的翻转。

## 代码
```csharp
Shader "Unlit/CS16_SkyBox"
{
    Properties
    {
        _MainTex ("Texture", 2D) = "white" {}
    }
    SubShader
    {
        //保证天空盒最先被渲染
        Tags { "RenderType"="Opaque" "Queue"="Background"}
        LOD 100

        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "UnityCG.cginc"

            struct v2f
            {
                float2 uv : TEXCOORD0;
                float4 pos : SV_POSITION;
            };

            sampler2D _MainTex;
            float4 _MainTex_ST;
            float4 _MainTex_HDR;

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = TRANSFORM_TEX(v.texcoord, _MainTex);

                #if UNITY_REVERSED_Z
                    o.pos.z = o.pos.w * 0.00001f;
                #else
                    o.pos.z = o.pos.w * 0.99999f;
                #endif

                return o;
            }

            half4 frag (v2f i) : SV_Target
            {
                half4 col = tex2D(_MainTex, i.uv);
                col.rgb = DecodeHDR(col, _MainTex_HDR);
                return col;
            }
            ENDCG
        }
    }
}
```

# 水面反射
## 反射矩阵
### 平面的表示方法
设水面所在平面的法线向量为$\vec{n}$，从原点出发向该平面作一条垂线（即法线所在方向），与平面的交点设为$P_0$，那么平面上任意一点$P$与$P_0$的连线所构成的向量$\overrightarrow{PP_0}$必定垂直于法线$\vec{n}$，由此可得：

$$ \vec{n} ~\cdot~ \overrightarrow{PP_0} = 0 $$

$$ \vec{n} \cdot (P - P_0) = 0 $$

$$ \vec{n} \cdot P - \vec{n} \cdot P_0 = 0 $$

令$d = - \vec{n} \cdot P_0$，不难发现，如果我们将 $P_0$ 看做从原点指向 $P_0$ 的一条向量的话，那么该标量 $d$ 恰好等于原点到该平面的距离，因此我们可以用如下等式来表示一个平面：

$$ \vec{n} \cdot P + d = 0 $$

如果平面面向原点，则$d$为正，如果平面背向原点，则$d$为负。

为了便于进行矩阵运算，我们会使用一个四维向量 $(\vec{n}, d)$，即 $(n_x, n_y, n_z, d)$ 来表示平面，这样一来，我们只需要将空间中任意一点 $(p_x, p_y, p_z, 1)$ 与之相乘（即将坐标带入$\vec{n} \cdot P + d = 0$中），**若结果大于零，则该点在平面前方，以此类推**。

由此我们也引入了平面的一般式方程，即：

$$ Ax + By + Cz + D = 0 $$

其中$(A,B,C)$对应平面法向量，$D$对应平面与原点之间的距离。

### 反射矩阵推导
<!-- 这是一张图片，ocr 内容为： -->
![](/img/Kerry/19_天空与水面_展示角色/1778479093839-4a20f99e-89cd-44b8-be57-a9a7b3461483.png)

如图，假设平面法线（从原点出发）与平面的交点为 $P_0$，$Q$ 表示空间内任意一点，$Q'$ 为 $Q$ 在平面上的投影，$Q''$ 为 $Q$ 关于平面的对称点，我们可以获得如下关系：

$$ \vec{r} = Q - P_0 $$

$$ \vec{a} = (\vec{r} \cdot \vec{n}) \times \vec{n} $$

$$ \vec{b} = \vec{r} - \vec{a} $$

$$ \vec{c} = -\vec{a} $$

$$ Q' = p + b $$

$$ Q'' = Q' + c $$

显然$P_0$ 在平面上，因此还有$\vec{n} \cdot P_0 + d = 0$。

<!-- 这是一张图片，ocr 内容为： -->
![](/img/Kerry/19_天空与水面_展示角色/1778479359209-953110c4-42e2-4f1f-bd16-3dad5842e4ca.jpeg)

经过如上推导后，我们可以得到：

$$ Q'' = Q - 2 \times (Q \cdot \vec{n} + d) \times \vec{n} $$

我们将其拆开成分量形式后可以得到：

$$ Q''_x = Q_x - 2 \times (Q_x \cdot n_x + Q_y \cdot n_y + Q_z \cdot n_z + d) \times \overrightarrow{n_x} $$

$$ Q''_y = Q_y - 2 \times (Q_x \cdot n_x + Q_y \cdot n_y + Q_z \cdot n_z + d) \times \overrightarrow{n_y} $$

$$ Q''_z = Q_x - 2 \times (Q_x \cdot n_x + Q_y \cdot n_y + Q_z \cdot n_z + d) \times \overrightarrow{n_z} $$

{% note danger %}
由于 $Q \cdot \vec{n}$ 是一个标量，因此上式中只有最前面的 $Q$ 和末尾的 $\vec{n}$ 需要被拆成分量形式，我们将 $Q \cdot \vec{n}$ 也拆开只是为了方便后续将其转化为矩阵。

{% endnote %}

将上式合并同类项后可得：

$$ Q''_x = Q_x \times (1 - 2 \times n_x^2) + Q_y \times (-2 \times n_y \times n_x) + Q_z \times (-2 \times n_z \times n_x) - 2 \times d \times \vec{n_x} $$

$$ Q''_y = Q_x \times (- 2 \times n_x \times n_y) + Q_y \times (1 - 2 \times n_y^2) + Q_z \times (-2 \times n_z \times n_y) - 2 \times d \times \vec{n_y} $$    

$$ Q''_z = Q_x \times (-2 \times n_x \times n_z) + Q_y \times (-2 \times n_y \times n_z) + Q_z \times (1 - 2 \times n_z^2) - 2 \times d \times \vec{n_z} $$

写成矩阵形式即：

$$ \begin{bmatrix} Q''_x \\[5pt] Q''_y \\[5pt] Q''_z \\[5pt] 1\end{bmatrix} = \begin{bmatrix} 1 - 2n_x^2 & -2n_yn_x & -2n_zn_x & -2dn_x \\[5pt] -2n_xn_y & 1-2n_y^2 & -2n_zn_y & -2dn_y \\[5pt] -2n_xn_z & -2n_yn_z & 1-2n_z^2 & -2dn_z \\[5pt] 0 & 0 & 0& 1 \end{bmatrix} \begin{bmatrix} Q_x \\[5pt] Q_y \\[5pt] Q_z \\[5pt] 1 \end{bmatrix} $$

由此我们便推导出了反射矩阵`Reflection Matrix`。

### Unity中的`Reflection Matrix`计算函数
```csharp
 // Calculates reflection matrix around the given plane
static void CalculateReflectionMatrix(ref Matrix4x4 reflectionMat, Vector4 plane)
{
    reflectionMat.m00 = (1F - 2F * plane[0] * plane[0]);
    reflectionMat.m01 = (- 2F * plane[0] * plane[1]);
    reflectionMat.m02 = (- 2F * plane[0] * plane[2]);
    reflectionMat.m03 = (- 2F * plane[3] * plane[0]);

    reflectionMat.m10 = (- 2F * plane[1] * plane[0]);
    reflectionMat.m11 = (1F - 2F * plane[1] * plane[1]);
    reflectionMat.m12 = (- 2F * plane[1] * plane[2]);
    reflectionMat.m13 = (- 2F * plane[3] * plane[1]);

    reflectionMat.m20 = (- 2F * plane[2] * plane[0]);
    reflectionMat.m21 = (- 2F * plane[2] * plane[1]);
    reflectionMat.m22 = (1F - 2F * plane[2] * plane[2]);
    reflectionMat.m23 = (- 2F * plane[3] * plane[2]);

    reflectionMat.m30 = 0F;
    reflectionMat.m31 = 0F;
    reflectionMat.m32 = 0F;
    reflectionMat.m33 = 1F;
}
```

#### 静态函数
我们通常会将这些只包含纯数学运算，且不需要类的成员变量或函数的函数声明为静态函数。

**静态函数中不能调用类成员变量和函数，因为该函数不属于类对象，仅属于类本身；**

这意味着**我们可以通过`类名.静态函数名`来直接调用该函数；**

静态函数在运行时，不论声明了多少个该类对象，**静态函数在内存中只会存在一个实例**，存储在**只读代码区/代码段**。

+ 之所以声明为静态函数，是因为**普通函数**在通过类似`myObject.Calculate(...)`调用时，**编译器会将该类对象本身的内存地址同样传入该函数中**，即`Calculate(AddressOfMyObject, parameter1, parameter2...)`，这意味着每次调用都要多占用一个 CPU 寄存器来存这个地址，多执行一次寻址操作；而**静态函数则无需传入内存地址**，因为静态函数并不需要知道被哪个类对象调用。

#### 内存分区
##### 代码段 (Code Segment / Text Segment)
存放程序的可执行机器指令`Binary Instructions`的内存区域。

+ **只读性**`Read-Only`： 为了防止程序在运行过程中意外修改自身的指令（即防止“自修改代码”），该区域受操作系统内核保护，任何写入尝试都会触发 段错误`Segmentation Fault`。
+ **共享性**： 对于同一个程序的多个进程实例，操作系统通常只在物理内存中保留一份代码段副本，以节省资源。

##### 数据段 (Data Segment / Static Segment)
存放生命周期贯穿整个程序执行过程的数据（全局变量和静态变量）。

##### 堆区 (Heap)
用于动态分配内存的非结构化区域，其空间由开发者或运行时环境（Runtime）手动管理。

+ 内存地址不连续；
+ 在 C++ 中通过`malloc/free`或`new/delete`手动管理。
+ 在 C# (Unity) 中，由垃圾回收器`Garbage Collector, GC`自动化管理。

##### 栈区 (Stack)
由编译器自动分配和释放的内存区域，遵循 后进先出 (LIFO) 原则。

+ 内存地址连续；
+ 由 CPU寄存器（Stack Pointer）直接操作，空间非常有限（通常几 MB）

## `GL.invertCulling`
我们现在已经计算出了反射矩阵，这意味着我们已经可以实现将物体上的每一个顶点镜像到水面下方，但这又引申出了下一个问题：**GPU将无法正确判断模型的正面和背面**。

我们曾在《入门精要》中学习过，三角形片元的三个顶点如果按照逆时针顺序相连则为正面，顺时针相连则为背面，但是**各个顶点经过镜像之后，顶点之间的连接顺序并不会发生变化，但是连接方向则与之相反**，如下图所示：

<!-- 这是一张图片，ocr 内容为： -->
![](/img/Kerry/19_天空与水面_展示角色/1778488931152-fd732ed1-667b-4225-845f-4493fb1c202c.jpeg)

这也就意味着模型的正面会被当成背面而被剔除掉，因此，**我们需要将`GL.invertCulling`设置为`true`，该功能将会反转 GPU 背面剔除的判断规则，即从逆时针连接为正面翻转为顺时针连接为正面**，由此我们便能正常渲染出镜像后的物体了。

## 物体镜像
既然我们已经获得了反射矩阵，那我们貌似可以直接将物体镜像到水面下方，但这就意味着原先水面上方的物体就被移动到水面下方了，虽然我们可以通过复制一个物体来实现，但如果该物体会不断移动，那我们还得想办法实时传递该物体的`Transform`，性能消耗太大，因此我们将使用摄像机的观察空间变换矩阵来解决这个问题。

观察空间坐标等于观察空间变换矩阵乘以世界空间坐标，如果我们能提前将世界空间坐标乘以反射矩阵，然后再乘以观察空间变换矩阵，那么我们就可以传入镜像后的物体位置了。

```csharp
//“镜像物体”
reflectCamera.worldToCameraMatrix = currentCam.worldToCameraMatrix * reflection;
```

上式中，我们将反射相机的观察空间变换矩阵**右乘**反射矩阵，这样一来，在做观察空间变换的时候，**世界空间坐标就会先乘以反射矩阵，然后再乘以观察空间变换矩阵**，也就是先将物体镜像到水面下方，然后再转化到观察空间中。

## 斜投影矩阵`Oblique Projection Matrix`
我们还需要考虑一些其他的情况，如果水面模型的下方还有其他的物体的话，比如一些我们希望隐藏在水面下方的物体，那么这些物体也会一并被反射相机捕捉并渲染，这肯定是我们不想看到的，因此我们需要想办法剔除掉水面下方的部分。我们将通过改变反射相机的近裁剪面来进行剔除。

我们希望实现的结果是，**反射相机能够以水面所在平面作为近裁剪平面**，那么我们就可以一并剔除水面下方的所有物体。

如果我们需要将水面作为近裁剪平面，那么水面在观察空间中的 $z$ 值就应当是零，这也就意味着我们需要对观察空间进行深度重映射，也就是通过**将原先的视椎体中距离水面最远的点的深度作为分母**，那么下一个问题就是获取这个深度最大的顶点。视椎体原先的远裁剪平面上总共就只有 4 个顶点，**我们只需要判断这 4 个顶点中哪个顶点与原点的连线最接近水面法线方向即可**。

下一步就是获得该顶点的深度，显然我们可以利用NDC坐标空间归一化的特性，通过 $z_{ndc} = 1$ 来直接获得远裁剪平面的深度，然后将其反变换转化回观察空间即可，但问题在于，不存在 NDC 空间变换矩阵这种东西，因为从裁剪空间转化到 NDC 坐标空间需要除以 $w$，而这种除法操作并不是线性的，只能通过 GPU 来完成，因此不存在这样的矩阵，所以**我们只能通过使用裁剪空间变换矩阵的逆矩阵来进行反变换**，但是从 NDC 坐标空间转换回裁剪空间需要乘以 $w$，但是我们并不知道最远处的顶点所对应的 $w$ 值，因此我们需要做一些特殊处理：

我们已经知道在 NDC 坐标空间中，$z_{ndc} = 1$ 代表远裁剪平面，且远裁剪平面上的该顶点的 $xy$ 等于 $-1或1$，而 $z_{ndc} = \frac{z_{clip}}{w_{clip}}$，因此，我们可以直接取 $z_{clip} = w_{clip} = 1$，这样一来，该顶点从裁剪空间变换到 NDC 空间之后，坐标正好还是该顶点的 NDC 空间坐标，然后通过投影空间变换矩阵的逆矩阵将其转回到观察空间，代码如下：

```csharp
//clipPlane为水面在观察空间中的四维向量
Vector4 q = projection.inverse * new Vector4(
    Mathf.Sign(clipPlane.x),    //Mathf.Sign(x): x>=0 返回1 x<0 返回0
    Mathf.Sign(clipPlane.y),    //也就是通过镜面法线的xy判断镜面的朝向
    1.0F,                       //然后通过裁剪空间->观察空间得到视椎体中距离平面最远的点
    1.0F
);
```

下一步就是进行深度重映射，我们知道**裁剪空间中的深度 $z_{clip}$ 值只和裁剪空间变换矩阵（投影矩阵）的第三行 $Row3$ 有关，同理 $w_{clip}$ 只和 $Row4$ 有关**，因此**观察空间**中的点 $x$ 都具有以下关系：

$$ z_{clip} = Row3 \cdot x \tag{a} $$

$$ w_{clip} = Row4 \cdot x \tag{b} $$

既然我们需要进行深度重映射，那么我们自然需要想办法修改投影矩阵的 $Row3$，我们可以考虑从深度的两个端点：近裁剪平面和远裁剪平面下手，以此构建两个约束条件，从而求出 $Row3$：

### 近裁剪平面
我们可以使用和求出最短点 $q$ 一样的方式求出近裁剪平面上的点在裁剪空间中的表示。由于近裁剪平面上的点在 NDC 空间中的 $z_{ndc} = -1$，$z_{ndc} = \frac{z_{clip}}{w_{clip}} = -1$，因此近裁剪平面上的点有以下关系式：

$$ z_{clip} + w_{clip} = 0 $$

令 $P_0$ 为观察空间中水面（近裁剪平面）上任意一点，代入前面提到的两个关系式：

$$ Row3 \cdot P_0 + Row4 \cdot P_0 = 0 $$

$$ (Row3 + Row4) \cdot P_0 = 0 $$

由于 $P_0$ 位于水面（近裁剪平面）上，而我们之前已经求出了水面在观察空间中的表示方式，因此显然有 $clipPlane \cdot P_0 = 0$，但是我们先假设水面（近裁剪平面）的四维向量为 $c$，原因将在后面讲述，读者可先将其当成 $clipPlane$ 来看待，那么由平面的表示方式可得：

$$ c \cdot P_0 = 0 \tag{1} $$

代入上式可得：

$$ Row3 + Row4 = c $$

$$ Row3 = c - Row4 \tag{2} $$

### 远裁剪平面
我们尚不知道远裁剪平面在我们改变近裁剪平面之后会如何变化，但我们必须要保证视椎体中最远的顶点 $q$ 必须包含在远裁剪平面中。

我们在前面已经推导过：

$$ z_{clip}^q = w_{clip}^q = 1 $$

$$ Row3 \cdot q = Row4 \cdot q = 1 $$

代入 $(a)(b)$ 式后可得：

$$ Row3 \cdot q = Row4 \cdot q = 1 $$

代入 $(2)$ 式后可得：

$$ (c - Row4) \cdot q = Row4 \cdot q = 1 $$

我们先化简左侧的等式：

$$ c \cdot q - 2 \times (Row4 \cdot q) = 0 $$

代入右侧的 $Row4 \cdot q = 1$ 等式：

$$ c \cdot q = 2 \tag{3} $$

此时我们可以关注到一些奇怪的地方，如果我们假设 $c = clipPlane$，那就意味着近裁剪平面和远裁剪平面上的 $q$ 存在着恒定的代数关系，但是此处的 $clipPlane$ 和 $q$ 全部都是已知量，前者从世界空间转化到观察空间，后者从 NDC 空间反推到观察空间，而现在我们的等式 $(3)$ 却要求两个已知量相乘的结果必须等于 2，这显然是不合理的，我们需要找到等式 $(3)$ 中的未知量，因此我们需要从平面的表示方法入手。

由平面的一般式方程可以看出，平面的四维向量乘以任意非零常数之后依然表示同一个平面，因此我们可以推导出：

$$ c = k \times clipPlane $$

将该式代入等式 $(2)$ 中：

$$ k = \frac{2}{clipPlane \cdot q} $$

由此我们就求出了最终的 $c$：

$$ c = clipPlane \times \frac{2}{clipPlane \cdot q} $$

由于我们并不需要修改投影矩阵的 $Row4$，因此我们只需要根据 $Row3 = c - Row4$ 求出新的 $Row3$ 即可。

### 代码
```csharp
static Matrix4x4 CalculateObliqueMatrix(Matrix4x4 projection, Vector4 clipPlane) 
{
        Vector4 q = projection.inverse * new Vector4(
            Mathf.Sign(clipPlane.x),    //Mathf.Sign(x): x>=0 返回1 x<0 返回0
            Mathf.Sign(clipPlane.y),    //也就是通过镜面法线的xy判断镜面的朝向
            1.0F,                       //然后通过裁剪空间->观察空间得到视椎体中距离平面最远的点
            1.0F
            );
    Vector4 c = clipPlane * (2.0F / (Vector4.Dot(clipPlane, q)));
    // third row = clip plane - fourth row
    projection[2] = c.x - projection[3];
    projection[6] = c.y - projection[7];
    projection[10] = c.z - projection[11];
    projection[14] = c.w - projection[15];

    return projection;
}
```

## `C#`代码
```csharp
using System;
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Rendering;

[ExecuteInEditMode]
public class PlanarReflection : MonoBehaviour 
{
    public LayerMask _reflectionMask = -1;
    public bool _reflectSkybox = false;
    public float _clipPlaneOffset = 0.07F;
    //反射图属性名
    const string _reflectionTex = "_ReflectionTex";
    Camera _reflectionCamera;
    Vector3 _oldpos;
    RenderTexture _bluredReflectionTexture;
    Material _sharedMaterial;
    //模糊效果相关参数
    public bool _blurOn = true;
    [Range(0.0f, 5.0f)]
    public float _blurSize = 1;
    [Range(0, 10)]
    public int _blurIterations = 2;
    [Range(1.0f, 4.0f)]
    public float _downsample = 1;
    //记录上述模糊参数，用于判断参数是否发生变化   
    private bool _oldBlurOn;
    private float _oldBlurSize;
    private int _oldBlurIterations;
    private float _oldDownsample;
    //模糊shader
    private Shader _blurShader;
    private Material _blurMaterial;
    //用来判断当前是否正在渲染反射图
    private static bool _insideRendering;

    Material BlurMaterial 
    {
        get {
            if (_blurMaterial == null) {
                _blurMaterial = new Material(_blurShader);
                return _blurMaterial;
            }
            return _blurMaterial;
        }
    }

    void Awake() 
    {
        _oldBlurOn = _blurOn;
        _oldBlurSize = _blurSize;
        _oldBlurIterations = _blurIterations;
        _oldDownsample = _downsample;
    }

    void Start() 
    {
        _sharedMaterial = GetComponent<MeshRenderer>().sharedMaterial;
        _blurShader = Shader.Find("Hidden/KawaseBlur");
        if (_blurShader == null)
            Debug.LogError("缺少Hidden/KawaseBlur Shader");
    }

    bool _blurParamChanged;
    void Update()
    {
        if (_blurParamChanged)
        {
            _oldBlurOn = _blurOn;
            _oldBlurSize = _blurSize;
            _oldBlurIterations = _blurIterations;
            _oldDownsample = _downsample;
        }

        if (_blurOn != _oldBlurOn || _blurSize != _oldBlurSize || _blurIterations != _oldBlurIterations || _downsample!= _oldDownsample)
        {
            _blurParamChanged = true;
        }
    }

    //创建反射用的摄像机
    Camera CreateReflectionCamera(Camera cam) 
    {
        //生成Camera
        String reflName = gameObject.name + "Reflection" + cam.name; 
        GameObject go = new GameObject(reflName);
        go.hideFlags = HideFlags.HideAndDontSave;
        Camera reflectCamera = go.AddComponent<Camera>();

        //设置反射相机的参数
        HoldCameraSettings(reflectCamera);

        //创建反射相机的目标渲染纹理
        if (!reflectCamera.targetTexture) 
        {
            reflectCamera.targetTexture = CreateTexture(cam);
        }

        return reflectCamera;
    }
    //设置反射相机的参数
    void HoldCameraSettings(Camera heplerCam)
    {
        heplerCam.backgroundColor = Color.black;
        heplerCam.clearFlags = _reflectSkybox ? CameraClearFlags.Skybox : CameraClearFlags.SolidColor;
        heplerCam.renderingPath = RenderingPath.Forward;
        heplerCam.cullingMask = _reflectionMask;
        heplerCam.allowMSAA = false;

        //先关闭摄像机 等后续参数全部设置完再打开
        heplerCam.enabled = false;
    }
    //创建RT 
    RenderTexture CreateTexture(Camera sourceCam) 
    {
        int width = Mathf.RoundToInt(Screen.width / _downsample);
        int height = Mathf.RoundToInt(Screen.height / _downsample);
        RenderTextureFormat formatRT = sourceCam.allowHDR ? RenderTextureFormat.DefaultHDR : RenderTextureFormat.Default;
        RenderTexture rt = new RenderTexture(width, height, 24, formatRT);
        rt.hideFlags = HideFlags.DontSave;
        return rt;
    }
    //内置回调函数，物体渲染之前会先调用该函数
    void OnWillRenderObject() 
    {
        Camera currentCam = Camera.current;
        if (currentCam == null) 
        {
            return;
        }

#if !UNITY_EDITOR
        if (!currentCam.gameObject.CompareTag("MainCamera"))
            return;     //如果当前不是主摄像机在渲染画面的话就返回
#endif

        if (_insideRendering) 
        {
            return;     //监测当前是否正在渲染反射图，以免反射图与反射图之间互相渲染
                        //从而导致无限死锁套娃
        }
        _insideRendering = true;

        if (_reflectionCamera == null) 
        {
            _reflectionCamera = CreateReflectionCamera(currentCam);
        }

        //渲染反射图
        RenderReflection(currentCam, _reflectionCamera);

        //是否对反射图进行模糊
        if (_reflectionCamera && _sharedMaterial) 
        {
            if (_blurOn) {
                if (_bluredReflectionTexture == null)
                    _bluredReflectionTexture = CreateTexture(currentCam);
                PostProcessTexture(currentCam, _reflectionCamera.targetTexture, _bluredReflectionTexture);
                _sharedMaterial.SetTexture(_reflectionTex, _bluredReflectionTexture);
            }
            else {
                _sharedMaterial.SetTexture(_reflectionTex, _reflectionCamera.targetTexture);
            }
        }

        _insideRendering = false;
    }

    //调用反射相机，渲染反射图
    void RenderReflection(Camera currentCam, Camera reflectCamera) 
    {
        if (reflectCamera == null) 
        {
            Debug.LogError("反射Camera无效");
            return;
        }
        if (_sharedMaterial && !_sharedMaterial.HasProperty(_reflectionTex))
        {
            Debug.LogError("Shader中缺少_ReflectionTex属性");
            return;
        }
        //保持反射相机的参数
        HoldCameraSettings(reflectCamera);

        if (_reflectSkybox) 
        {
            if (currentCam.gameObject.GetComponent(typeof(Skybox))) {
                Skybox sb = (Skybox)reflectCamera.gameObject.GetComponent(typeof(Skybox));
                if (!sb) {
                    sb = (Skybox)reflectCamera.gameObject.AddComponent(typeof(Skybox));
                }
                sb.material = ((Skybox)currentCam.GetComponent(typeof(Skybox))).material;
            }
        }

        bool isInvertCulling = GL.invertCulling;
        GL.invertCulling = true;

        Transform reflectiveSurface = this.transform; //waterHeight;

        Vector3 eulerA = currentCam.transform.eulerAngles;

        reflectCamera.transform.eulerAngles = new Vector3(-eulerA.x, eulerA.y, eulerA.z);
        reflectCamera.transform.position = currentCam.transform.position;

        Vector3 pos = reflectiveSurface.transform.position;
        Vector3 normal = reflectiveSurface.transform.up;
        float d = -Vector3.Dot(normal, pos) - _clipPlaneOffset;
        Vector4 reflectionPlane = new Vector4(normal.x, normal.y, normal.z, d);

        Matrix4x4 reflection = Matrix4x4.zero;
        reflection = CalculateReflectionMatrix(reflection, reflectionPlane);
        _oldpos = currentCam.transform.position;
        Vector3 newpos = reflection.MultiplyPoint(_oldpos);
        reflectCamera.transform.position = newpos;

        //“镜像物体”
        reflectCamera.worldToCameraMatrix = currentCam.worldToCameraMatrix * reflection;

        Vector4 clipPlane = CameraSpacePlane(reflectCamera, pos, normal, 1.0f);

        Matrix4x4 projection = currentCam.projectionMatrix;
        projection = CalculateObliqueMatrix(projection, clipPlane);
        reflectCamera.projectionMatrix = projection;

        reflectCamera.Render();

        GL.invertCulling = isInvertCulling;
    }

    static Matrix4x4 CalculateObliqueMatrix(Matrix4x4 projection, Vector4 clipPlane) 
    {
            Vector4 q = projection.inverse * new Vector4(
                Mathf.Sign(clipPlane.x),    //Mathf.Sign(x): x>=0 返回1 x<0 返回0
                Mathf.Sign(clipPlane.y),    //也就是通过镜面法线的xy判断镜面的朝向
                1.0F,                       //然后通过裁剪空间->观察空间得到视椎体中距离平面最远的点
                1.0F
                );
        Vector4 c = clipPlane * (2.0F / (Vector4.Dot(clipPlane, q)));
        // third row = clip plane - fourth row
        projection[2] = c.x - projection[3];
        projection[6] = c.y - projection[7];
        projection[10] = c.z - projection[11];
        projection[14] = c.w - projection[15];

        return projection;
    }

    static Matrix4x4 CalculateReflectionMatrix(Matrix4x4 reflectionMat, Vector4 plane) 
    {
        reflectionMat.m00 = (1.0F - 2.0F * plane[0] * plane[0]);
        reflectionMat.m01 = (-2.0F * plane[0] * plane[1]);
        reflectionMat.m02 = (-2.0F * plane[0] * plane[2]);
        reflectionMat.m03 = (-2.0F * plane[3] * plane[0]);

        reflectionMat.m10 = (-2.0F * plane[1] * plane[0]);
        reflectionMat.m11 = (1.0F - 2.0F * plane[1] * plane[1]);
        reflectionMat.m12 = (-2.0F * plane[1] * plane[2]);
        reflectionMat.m13 = (-2.0F * plane[3] * plane[1]);

        reflectionMat.m20 = (-2.0F * plane[2] * plane[0]);
        reflectionMat.m21 = (-2.0F * plane[2] * plane[1]);
        reflectionMat.m22 = (1.0F - 2.0F * plane[2] * plane[2]);
        reflectionMat.m23 = (-2.0F * plane[3] * plane[2]);

        reflectionMat.m30 = 0.0F;
        reflectionMat.m31 = 0.0F;
        reflectionMat.m32 = 0.0F;
        reflectionMat.m33 = 1.0F;

        return reflectionMat;
    }

    Vector4 CameraSpacePlane(Camera cam, Vector3 pos, Vector3 normal, float sideSign) 
    {
        Vector3 offsetPos = pos + normal * _clipPlaneOffset;
        Matrix4x4 m = cam.worldToCameraMatrix;
        Vector3 cpos = m.MultiplyPoint(offsetPos);
        Vector3 cnormal = m.MultiplyVector(normal).normalized * sideSign;

        return new Vector4(cnormal.x, cnormal.y, cnormal.z, -Vector3.Dot(cpos, cnormal));
    }

    //对反射图进行图像处理(利用command buffer实现)
    private Dictionary<Camera, CommandBuffer> _cameras = new Dictionary<Camera, CommandBuffer>();
    void PostProcessTexture(Camera cam, RenderTexture source, RenderTexture dest)
    {
        //参数有变化需要刷新commandbuffer
        if (_blurParamChanged)
        {
            if (_cameras.ContainsKey(cam))
                cam.RemoveCommandBuffer(CameraEvent.BeforeForwardOpaque, _cameras[cam]);
            _cameras.Remove(cam);
        }
        //已经设置了commandbuffer就不用再执行了
        if (_cameras.ContainsKey(cam))
            return;

        CommandBuffer buf = new CommandBuffer();
        buf.name = "Blur Reflection Texture";
        _cameras[cam] = buf;
        float width = source.width;
        float height = source.height;
        int rtW = Mathf.RoundToInt(width / _downsample);
        int rtH = Mathf.RoundToInt(height / _downsample);

        int blurredID = Shader.PropertyToID("_Temp1");
        int blurredID2 = Shader.PropertyToID("_Temp2");
        buf.GetTemporaryRT(blurredID, rtW, rtH, 0, FilterMode.Bilinear, source.format);
        buf.GetTemporaryRT(blurredID2, rtW, rtH, 0, FilterMode.Bilinear, source.format);

        buf.Blit((Texture)source, blurredID);
        for (int i = 0; i < _blurIterations; i++)
        {
            float iterationOffs = (i * 1.0f);
            buf.SetGlobalFloat("_Offset", iterationOffs / _downsample + _blurSize);
            buf.Blit(blurredID, blurredID2, BlurMaterial, 0);
            buf.Blit(blurredID2, blurredID, BlurMaterial, 0);
        }
        buf.Blit(blurredID, dest);

        buf.ReleaseTemporaryRT(blurredID);
        buf.ReleaseTemporaryRT(blurredID2);

        cam.AddCommandBuffer(CameraEvent.BeforeForwardOpaque, buf);
    }
}
```

# 添加水面的闪烁高光
一般来说，水面的闪烁高光密度都比较大，且至少要大于普通高光的密度，同时大小也肯定小于普通高光，因此我们可以通过重复进行一次高光的计算，但是调大噪声的密度以及强度，以此来获得更加密集的高光，同时通过将结果减去`BlinnThreshold`来去掉除去高光以外的部分，然后和普通高光结果进行叠加。
